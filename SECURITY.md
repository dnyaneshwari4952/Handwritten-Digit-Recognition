# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

We take the security of this project seriously. If you discover any security-related vulnerabilities, please follow these steps:

1. **Do NOT open a public GitHub issue.**
2. Report the vulnerability privately to the project repository owner or maintainer.
3. Include detailed steps to reproduce the vulnerability, along with proof of concept if applicable.

We will review the issue and release a patch as quickly as possible.
